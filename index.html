Zero-Poison: SW-MARL for Cache Pollution Mitigation in NDN

Conceived and implemented a novel Sliding Window Multi-Agent Reinforcement Learning defense framework to prevent adversarial Cache Pollution Attacks in Information-Centric Networking (NDN). Built independent Actor-Critic neural networks for distributed routers, tracking an 11-dimensional temporal feature space.

Key Algorithmic Contributions:
  • Zero-Poison Guarantee: Maintained 0.0% poisoned cache content under aggressive adversarial traffic floods.
  • Self-Healing Protocol: Designed an episode-based sliding window ($W=20\text{ to }200$) with a threshold reset rule ($P_{\text{window}} > 0 \implies Q \to 0$), enabling automatic recovery without permanent lockdown.
  • High Throughput: Achieved a 92.3% cache hit rate and 94.7% network throughput with only 0.3% false positives.
  • Research Publication: Submitted to ICICT 2026 under supervisor Prof. Nidhi Lal.

Academic Research & Publications

CONFERENCE SUBMISSION • ICICT 2026

Zero-Poison: Sliding Window Multi-Agent Reinforcement Learning for Cache Pollution Prevention in Named Data Networking

Kathulapalli Chakradhar Reddy (Lead), Indrasena Reddy, Himanshu, Rajat | Supervisor: Prof. Nidhi Lal
Department of Computer Science & Engineering, Visvesvaraya National Institute of Technology (VNIT), Nagpur

Abstract: In-network caching in Named Data Networking (NDN) provides significant latency reduction but remains vulnerable to Cache Pollution Attacks (CPA), where malicious actors flood bogus content to displace legitimate packets. Existing static countermeasures either react too slowly or induce permanent cache denial-of-service. In this paper, we propose a decentralized Sliding Window Multi-Agent Reinforcement Learning (SW-MARL) framework. Routers function as localized learning agents evaluating 11 temporal metrics across a sliding window buffer. By introducing a self-healing threshold reset mechanism ($P_{\text{window}} > 0$), the network successfully achieves 0% poisoned data served, recovers a 92.3% cache hit rate, and avoids permanent lockdown once attacks cease.
